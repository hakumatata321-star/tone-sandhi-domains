# Tone Sandhi Domains

Dataset card and licence for **Invented Mandarin-Style Utterances with Third-Tone Sandhi**, a fully synthetic dataset of 6,000 utterances built to study third-tone sandhi over hidden prosodic domains.

The full description is in [DATASET_DESCRIPTION.md](DATASET_DESCRIPTION.md).

The data files are distributed with the challenge that uses them and are not stored here. The generator is keyed to a withheld secret and is not published, so the release cannot be regenerated or matched against any external source.
